这一页列出默认配置下的全部快捷键。表里的 `Mod` 在 macOS 上是 ⌘，在 Windows / Linux 上是 Ctrl。

在「设置 → 快捷键」里可以逐条改键、加替代键、设为无，或用顶部的「启用快捷键」整体关掉；也可以切换到内置的另一套键位配置档。

## 通用规则

- **终端里的控制键归 shell**：焦点在终端里时，Ctrl（不带 Shift）或 Alt 加一个键的组合（如 Ctrl+C、Ctrl+D、Ctrl+R、Alt+B）不会被 Armadra 截走，即使你把它绑给了某条命令。Ctrl+Shift+字母与带 ⌘ 的组合不受影响。
- 「终端」列表示焦点在终端里时该键是否仍归 Armadra；「输入框」列表示焦点在输入框或可编辑区域时是否仍生效。
- 关掉「启用快捷键」后，页面不再接下表的任何命令，终端里的键全部交给 shell；只有窗口与系统自己的键（⌘W / Ctrl+W、⌘Q、Alt+F4）和下文「组件内的键」仍然有效。

## 组件内的键

下面这些只在对应控件有焦点或对应状态打开时生效，不可配置，也不受「启用快捷键」影响：

- Esc：画布回到选择工具、关闭面板与菜单、退出评论模式、取消文件拖放；
- 按住 Space 平移画布，Shift 加选，Mod+滚轮缩放；
- 节点标题上按 Enter 或 F2 重命名；
- 会话视图输入框：Enter 发送，Shift+Enter 换行；
- 评论框：Mod+Enter 发送，Enter / Tab 选择 @ 提及；
- 命令面板与快速打开：方向键选择，Enter 确认。

## 已知冲突与限制

- 在浏览器里打开的网页版：Ctrl / ⌘+T、Ctrl+W 等是浏览器保留键，页面拦不住；Ctrl+Shift+C、⇧⌘A、Ctrl+Shift+M、Ctrl+Shift+E / H 等可能先被浏览器处理。桌面版不受影响。
- 浏览器节点：关掉「启用快捷键」后，桌面版仍会把网页里带主修饰键的组合转给画布，这些键在网页里不生效。
- 服务器上的成员看不到「启用快捷键」总开关，只能改自己这台设备的键位。
- 手机与平板没有原生按键处理，外接键盘走同一张网页表；iPad 上 `Mod` 为 ⌘。
- 同一个组合键在条件同时成立时会冲突，设置页会标出。
