Armadra 云目前是邀请制内测，申请入口见[云服务](/cloud/)。控制台是浏览器里的管理界面：账号、团队、主机、授予、链接与设备信任都在这里。终端、Git 与 Agent 仍在你的电脑或服务器上执行。

## 注册

在控制台「注册」，填名字、邮箱与口令，再点验证邮件里的链接。邮箱验证后才能登记主机与分享。

## 个人空间与团队

每个账号有一个只属于自己的个人空间。左上角的空间菜单可以切换空间，菜单底部「创建团队」填名称与地址。主机、授予、链接与审计都归属一个空间。

## 邀请成员

在团队的「成员」点「邀请成员」，一次可填多个邮箱（逗号或换行分隔），选好角色后「发送邀请」。对方打开邀请，登录或注册后接受。待接受的邀请可以重新发送或撤销。

| 角色 | 能做什么 |
| --- | --- |
| 所有者 | 全部操作 |
| 管理员 | 管理成员、主机、授予、链接与团队设置，查看审计 |
| 成员 | 使用被授予的主机；团队设置允许时可以登记主机 |
| 账单 | 查看成员、用量与计划 |
| 访客 | 只看到被授予的主机 |

## 登记主机

主机就是一台运行 Armadra 的电脑或服务器。登记后它经中继出站连接，不开入站端口。

**桌面**：打开「设置 → 远程访问」，点「添加 Armadra 云」→「获取设备码」→「在浏览器中打开」。在控制台的「授权设备」页核对设备码与设备名，点「授权」。回到桌面，在「登记到」里选个人空间或团队，点「登记这台电脑」。

**服务器**：在服务器上运行

```sh
armadra-server cloud login --issuer <控制台地址> --space <团队地址>
```

终端打印设备码与验证地址，在浏览器里核对后授权。不带 `--space` 时登记到个人空间。也可以在控制台的「主机 → 登记主机 → 服务器」复制注册令牌与命令，用 `cloud register --token-stdin` 登记。Windows 上的服务器壳不支持这些命令。

## 授予访问

在团队的「授予」点「添加访问」：选对象（团队全员或某位成员）、主机、权限与到期（永不、7、30 或 90 天）。

| 权限 | 含义 |
| --- | --- |
| 只读 | 查看画布与终端画面 |
| 可编辑 | 再加上编辑画布 |
| 可执行 | 再加上开自己的终端、启动 Agent、读写文件与 Git |
| 可接管 | 再加上向他人的终端与 Agent 输入、回答审批 |

主机详情的「访问」页签按人列出最终权限，展开能看到每条来源，可以逐条撤销。主机登记到团队后，桌面的分享弹层里也能直接授予团队成员或按邮箱邀请。

## 设备信任

一台设备第一次经 Armadra 云进入主机时，要由已受信的设备放行。新设备上显示一个 6 位校验码并等待确认；主机所有者、团队管理员或你自己已受信的设备在控制台的「设备信任」或桌面横幅里点「信任」，输入这个校验码。校验码只在端到端通道里核对，云端看不到。

谁可以放行由团队设置的「新设备背书人」决定；「成员可以从自己已受信的设备批准」打开时，成员也能自己放行。

## 分享链接

在「链接」点「新建链接」：选主机、权限（缺省只读）、有效期（1、7 或 30 天）、次数上限与备注。链接只在创建时显示一次，复制后发给对方。对方打开后点「加入」，以访客进入画布；需要登录的链接先登录。撤销链接后，经它加入的人一并停用。

服务器上也可以生成链接：

```sh
armadra-server invite --cloud-link --issuer <控制台地址> --host --role viewer
```

## 在浏览器里打开主机

在主机列表里点「打开」，新标签页打开 `/h/<主机 id>`，画布与桌面上相同。登出控制台时，这些标签页一并断开。

完整的界面设计见 Armadra 仓库的[控制台设计](https://github.com/AMA-Link/Armadra/blob/main/docs/design/cloud-console.md)；服务器命令见[服务器部署指南](https://github.com/AMA-Link/Armadra/blob/main/docs/guides/server-deployment.md)。
