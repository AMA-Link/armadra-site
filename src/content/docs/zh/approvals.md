Agent 要运行命令、改文件或调用工具时，CLI 会向你请求权限。这一页讲这些请求在 Armadra 里出现在哪里、怎么答复、谁有资格答复，以及你怎么及时得到通知。

## 请求出现在哪里

同一个请求在几个地方都能看到，答复一处即可：

- **节点头部**：终端视图下，节点头部的状态胶囊变成「等待审批」，旁边出现「允许」与「拒绝」。Agent 在向你提问而不是请求权限时，是「等待回答」和「回答」按钮，点它跳到会话里作答。
- **会话视图的权限卡**：会话视图里，权限请求是一张卡，写明要做什么，命令类请求显示命令本身，工具调用可以点「详情」展开参数。有风险的操作会带「有风险」标记。
- **侧栏通知**：侧栏的「通知」列出所有「等待审批」「等待回答」「出错」的节点，点一项跳到对应节点；没有待处理的事时显示「没有需要处理的事」。
- **系统通知与手机推送**：见下文「通知」。

## 批准或拒绝

1. 看清卡片上写的是什么：命令、文件改动还是工具调用。拿不准就点「详情」。
2. 点「允许」或「拒绝」。会话视图的卡片按 CLI 提供的选项排列，常见的有：
   - 「本次」：只对这一次生效，「允许」或「拒绝」；
   - 「始终」：「始终允许」「始终拒绝」，之后同类请求不再询问，请慎用；
   - 「本会话允许」：只在当前会话里放行。
3. 答复后卡片变成结果，例如「已允许」「已始终允许」「已拒绝」，回合接着往下走。

键盘：焦点在卡片里时，按 Esc 拒绝，按数字键 1–9 选第几个选项。

Armadra 只是把你的选择交给 CLI，权限策略仍然是 CLI 的。想少被打扰，可以在启动时选别的权限模式（见[Agent 与 CLI](/docs/agents/)），每种模式的含义由 CLI 决定。

## 提问

有些 Agent 会向你提问而不是请求权限。提问同样出现在节点头部与会话里，用「提交」「继续」「拒绝」或「取消」作答。

## 谁能答复

不是所有能看到画布的人都能替 Agent 答复：

- 自己的电脑上，你就是答复人。
- 共享的工作空间里，答复要求「接管」角色（云上叫「可接管」）；「执行」角色只能答复自己启动的终端上的请求。查看、编辑角色看到的是「等待接管」，不能答复。
- Agent 请求关闭某个节点时，也会弹出「允许」与「拒绝」确认，同样只有接管角色能答；请求超时后会提示「这个请求已经失效。」

角色与授予方式见[自托管部署与远程访问](/docs/server-and-devices/)和[团队与控制台](/docs/teams-and-console/)。在服务器壳上，答复审批会记入审计。

## Armadra 不替人回答

- 协调者 `ama` 遇到成员的权限请求时只报告「被阻塞」，不会替你批准。
- 其他 Agent、自动化与工作流也不会自动点「允许」。工作流的「关卡」同样停下来等你「通过」或「拒绝」。
- 请求会一直挂着等你；过久没人处理时，节点上会出现「久未处理」，Agent 无进展时出现「停滞」或「空等」标记。可以在「设置 → 通知」里设置「停滞提醒」与「久未处理提醒」的分钟数。

Agent 之间通过连线读取上下文、发消息这类画布协作动作，本身不需要你逐次审批；它们只做连线与节点权限本来就允许的事。

## 通知

- **系统通知**：在「设置 → 通知」打开「需要你时通知」，Agent 请求权限时弹出「<节点标题> 等待审批」；同一页还有「提示音」与「音量」。
- **手机推送**：手机上有「接收哪些通知」的一组开关，可以单独打开或关闭「等待审批」「等待回答」「Agent 出错」「Agent 停滞」「工作流等待确认」等；已登记的设备在「设置 → 通知」的「推送设备」里。点通知直接打开对应节点。详见[手机 App](/docs/mobile/)。
- 手机上也能直接答复，不必回到电脑前，前提是你的角色允许。
