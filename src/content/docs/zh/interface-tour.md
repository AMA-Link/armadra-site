这一篇带你认一遍 Armadra 主窗口：每个区域放什么、从哪里进、怎么回来。界面上的按钮多数只有图标，鼠标悬停会显示名称，下面都用这些名称。快捷键里的 `⌘` 在 Windows 与 Linux 上对应 `Ctrl`，完整列表见[键盘快捷键](/docs/keyboard-shortcuts/)。

## 窗口分成哪几块

- **左侧栏**：工作空间与画布的列表、搜索、通知、设置入口。
- **画布**：占据中间的主要区域，节点、连线与白板都在这里。
- **Dock**：画布底部居中的一条工具栏。
- **右侧工具簇**：画布右上角一列图标，打开各种面板。
- **面板与抽屉**：从右侧滑出，或停靠在底部，用来看文件、Git、资源等。
- **缩略图**：画布右下角。

`⇧⌘L` 或标题栏上的「收起侧栏」「展开侧栏」可以折叠左侧栏，给画布让出空间。

## 左侧栏

- **新建画布**：在当前工作空间里新开一张画布并切过去。
- **置顶**：置顶过的画布集中显示在最上面。
- **工作空间分组**：「这台电脑」是本机的项目，标题右边的「添加项目」用来加新项目；连接了其他机器或别人分享了工作空间时，还会出现「我的其他电脑」和「他人分享」，后者会标出你的权限（只读、可编辑、可执行、可接管）。
- **工作空间与画布**：一个工作空间就是一个项目目录，下面列出它的画布。点工作空间名折叠或展开，点画布切换过去。悬停时出现的「工作空间菜单」里有重命名、分享、置顶、归档与删除；画布行有「画布操作」，可重命名、置顶与删除；画布行右侧的小圆点表示该画布里有 Agent 需要你，或有完成了但你还没看的内容。
- **搜索**（顶部放大镜）：一个输入框同时查画布、节点、工作空间、白板内容、文件与设置，点结果直接跳转。
- **通知**（顶部铃铛）：点开后会替换项目列表，只列出需要你处理的事：等待审批、等待回答、出错、交接待确认，按工作空间、画布、节点分层并带计数，点一条就跳到对应节点；处理完它自己消失。有待处理的事时铃铛右上角有一个点，再点一次或按 `Esc` 回到项目列表。
- **设置**（左下角）：打开设置，快捷键是 `⌘,`。

## 画布

画布是一张可以平移、缩放的无限平面。放什么、怎么操作见[画布与节点](/docs/canvas-and-nodes/)。

- 在空白处右键打开新建菜单；右键节点、连线、白板对象各有自己的菜单。
- `⌘` 加滚轮缩放，按住 `Space` 拖动平移，也可以选 Dock 上的「手形」工具。
- 右下角的缩略图可以点开或收起，用来在大画布上定位。
- 多设备或多人同时打开同一张画布时，右上角会显示在线的设备；别人分享给你的工作空间，顶部写着「<主人> 的 <工作空间>」。

## Dock

Dock 从左到右依次是：

1. **锁定视图** / **解锁视图**：锁住画布相机，防止误拖。
2. **新建**（`+`）：与空白处右键相同的新建菜单。
3. **撤销**、**重做**。
4. **一键整理**：按布局方向排列节点；选中了节点时变成「整理选中」；右键可以一次性选「纵向整理」或「横向整理」。
5. **白板工具**：选择、手形、画笔 / 高亮、形状、直线 / 箭头、文字与「引入…」。
6. **评论**：开关评论模式，右侧打开评论抽屉。
7. 右端：保存状态点（已保存、未保存、保存中、保存失败）和缩放控制；点「适应」让所有内容入镜，右键可选缩放档位。

手机上同样的内容排成一行，放不下时可以横向滑动。

## 右侧工具簇

画布右上角一列图标，从上到下：

| 图标名称 | 打开什么 |
| --- | --- |
| 节点与进度 | 当前画布所有节点的列表和最近更新时间，点「定位节点」跳过去 |
| 资源管理器 | 项目文件树，`⇧⌘E`；配合快速打开 `⌘P` 与项目搜索 `⇧⌘H` |
| 源码控制 | Git 工具窗口，停靠在窗口底部，`⇧⌘G` |
| 代码托管 | 代码托管账号里的 Issue 与 PR |
| 资源 | 本机与执行主机的内存、CPU 与会话进程，`⇧⌘U` |
| 分享 | 把当前工作空间分享给别人（仅工作空间的主人且它在本机时出现） |
| 退出焦点模式 | 只有处于焦点模式时出现 |
| 画布偏好 | 吸附、网格、专注模式、粘贴位置、输入设备等画布选项 |

各面板的用法见[编辑器与浏览器](/docs/editor-and-browser/)与 [Git 与 GitHub](/docs/git-and-github/)。

## 命令面板与快速打开

- **命令面板**（`⌘K`）：按名称运行任何命令，也能搜历史对话；最近用过的排在前面。
- **快速打开**（`⌘P`）：按文件名跳到项目里的文件。
- **项目搜索**（`⇧⌘H`）：在项目文件内容里搜索。

## 状态与提示

- 节点头部有状态胶囊，用同一套说法：运行中、空闲、等待审批、等待回答、已完成、已失败、已休眠等。
- 窗口顶部偶尔会出现一条提示：「画布保存失败」（点「重试」）、「本地服务已断开」（点「重连」）、「终端已降级为直连」（缺少 tmux 时，点「设置」查看）。
- Agent 需要你时，请求直接出现在节点头部，同时汇总到侧栏通知里，见[权限与审批](/docs/approvals/)。

## 在区域之间切换

- 用 `⌘K`、`⌘P`、`⇧⌘E`、`⇧⌘G` 等快捷键直达，不必伸手去点。
- 面板开着时再点一次同一个图标、或按 `Esc` 关闭。
- `⌘` 加方向键在节点之间移动选中；选中节点后 `⇧⌘⏎` 最大化，`⇧⌘F` 进入焦点模式（右上角出现「退出焦点模式」）。
- 窄屏（手机）上侧栏是覆盖式抽屉，底部出现「主导航」：画布、文件、Git、设置；详见[手机 App](/docs/mobile/)。
