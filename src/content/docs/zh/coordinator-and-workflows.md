## 协调者 ama

`ama` 是 Armadra 自带的协调 Agent。给它一个目标，它把子任务落成画布上的 Agent 节点、分派下去、等待并收齐结果。ama 节点头部的「N 成员」打开分派抽屉，列出各成员任务的状态与汇总；失败的任务可以重试。

成员遇到权限请求时，ama 只报告「被阻塞」，不替你回答。

## 团队编排

由 Agent 发起的编排支持几种形状：

- **并行**：多个成员同时做不同部分；
- **流水线**：上一个完成后下一个开始（`open-agent --after`）；
- **汇总**：多个成员的结果交给一个节点合并。

每个成员可以带一条自己的 Git worktree，互不干扰。

## 工作流

当一种协作方式稳定下来，可以把它存成工作流模板：

1. 协调者交一份草案；
2. 你在工作面板的「工作流」页确认成模板；
3. 之后填参数起跑，或在自动化里定时运行。

每次运行在画布上建一个 Frame 与各角色节点，关卡处停下等你确认；运行记录可以回看与对比。

## 什么时候用工作流

开放任务的路径会随新发现变化，适合先在画布上探索；步骤明确、需要反复执行的流程，再沉淀成工作流。两种方式可以结合。
