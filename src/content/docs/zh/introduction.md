Armadra 是一个本地优先的 AI 编程协作工作空间，让多个 AI 助手在同一张画布上分工、共享上下文并接续任务。

Claude Code、Codex、OpenCode、Pi、Oh My Pi 与 GitHub Copilot 这些 AI 编程助手（Agent）各自作为一个节点放在画布上，节点里直接运行对应的 CLI，沿用它的账户、模型与权限设置。你连接 Agent 来共享任务上下文，通过消息和交接让任务顺畅接续，在同一个工作空间里查看资料、进展与结果。

## 从使用一个 Agent，到组织多个 Agent

单独使用一个 Agent 时，上下文都在一个会话里。工作一旦跨越多个会话或多个 Agent，就会遇到这些问题：

- 接手的 Agent 不知道已经确认的决定、失败过的方法和结果的位置；
- 不同难度的步骤用同一个模型，预算没有花在最需要判断的地方；
- 多个终端窗口之间的关系只存在于你的脑子里。

Armadra 用画布把这些关系变成看得见、能操作的工作空间：

- **工作可以接续**：相连的 Agent 按范围读取摘要、转录与相关资料，交换消息并进行阶段性交接。
- **模型可以分工**：为节点选择不同模型，让经济模型承担边界明确的工作，让更强的模型处理复杂判断。当前分工由你或任务指令安排，自动难度路由尚未实现。
- **过程可以查看**：Agent、便签、编辑器、Git 差异、文件、浏览器和白板共同构成工作面。

## 节点里运行的是完整的 Agent 产品

Armadra 不重写 Agent。每个 Agent 节点启动的就是你已经在用的 CLI，复用它的多轮执行、工具调用和会话机制；Armadra 只负责节点身份、连线、消息与可读上下文。

## 适合哪些工作

- **软件工程**：需求分析、代码开发、测试、问题诊断与交叉审查。
- **算法与数据科学**：算法实现、数据处理、模型训练与评测、实验结果比较。
- **科研**：论文复现、计算实验、数据分析与可视化、研究结果复核。

## 运行方式

- **桌面应用**：macOS、Windows、Linux 安装包，工作空间记录保存在本机 SQLite 与工作区的 `.armadra/`，无需单独部署服务器。
- **自托管部署与远程访问**：把 Armadra 部署到自己的服务器或 NAS（服务器壳，没有窗口、常开），电脑与手机浏览器经 HTTPS 访问同一份页面，支持成员账号与按工作空间共享，见[自托管部署与远程访问](/docs/server-and-devices/)。

Agent 在承载工作空间的电脑或服务器上运行，模型请求和相关数据处理遵循所使用 CLI 与模型服务的设置及政策。

准备好了就去[安装](/docs/install/)。
