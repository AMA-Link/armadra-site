这一篇回答两件事：节点用哪个模型，以及机器和会话占了多少资源。

## 给节点选择模型

Armadra 不提供模型服务，模型由各 CLI 自己调用。你可以为每个节点指定启动时使用的模型：

1. 在 Agent 节点头部点「更多」，选「模型」。
2. 在列表里选一个模型；选「CLI 默认」表示不指定，沿用该 CLI 自己的设置。
3. 提示「下一次启动使用 …」时，说明当前会话不受影响，新模型在节点下次启动或接回会话时生效。

列表只对支持选择模型的 Agent 出现。候选来自该 CLI 自己的别名与配置（例如 Codex 配置文件里写的模型），并参考公开的模型目录补充；联网取不到时退回一份内置的常用列表。你实际能用哪些模型，仍取决于你在 CLI 里登录的账户与套餐。

默认使用的 Agent 与权限模式在「设置 → 默认」里设置，见[设置、更新与数据](/docs/settings-and-updates/)。

## 资源面板：机器和会话占了多少

资源面板显示的是机器与终端会话的负载，不是模型费用。

1. 点右上角工具簇里的「资源」，或按 ⇧⌘U（Windows / Linux 为 Ctrl+Shift+U）。
2. 「执行主机」部分显示 CPU、内存、交换、磁盘和「内存压力」（正常 / 偏紧 / 紧张）；有远程主机时可按「全部主机」「本机」筛选。
3. 「会话」列表按 CPU、内存或名称排序；每个会话可以展开进程树，点「定位到节点」跳到画布上的节点，点「结束会话」把它停掉（会先确认）。会话内存是进程树的估计值，共享页会重复计入，不等于独占内存。
4. 休眠中的会话显示「已休眠，不占内存」。
5. 「孤立会话」列出没有对应节点的会话，可以「附着到新节点」或「终止」。
6. 「平台组件」列出 Armadra 自己的进程占用。

相关设置在「设置 → 本机服务」的「电源与资源」：

| 设置 | 作用 |
| --- | --- |
| 防休眠策略 | 从不 / 有活跃 Agent 会话时 / 手动 |
| 工作时保持唤醒 | Agent 工作期间阻止系统空闲睡眠 |
| 采样间隔 | 资源数据多久刷新一次 |
| 内存提醒阈值 | 1、2、4、8、16 GB 可选；会话超过阈值时变色并提醒一次，不会自动处置 |

## 用量与费用统计

模型用量与额度统计暂未开放，界面里没有对应入口。要看账户的用量与额度，用各 CLI 自带的命令或官网；团队使用 Armadra 云时，可在控制台查看团队的用量与计划，见[团队与控制台](/docs/teams-and-console/)。
