手机上的 Armadra 是一个客户端：它连到你电脑或服务器上运行的 Armadra，用同一份画布页面查看节点、答复审批、敲几个终端按键。终端、Git 与 Agent 仍在电脑或服务器上执行，手机上不启动 CLI。

## 安装

- **Android**：在[发布页](https://github.com/AMA-Link/Armadra/releases/tag/{{tag}})下载 [`armadra-mobile_{{version}}_android.apk`](https://github.com/AMA-Link/Armadra/releases/download/{{tag}}/armadra-mobile_{{version}}_android.apk)，按系统提示允许该来源安装未知来源应用后手动安装。
- **iOS**：iOS 版尚未上架，暂时没有下载方式。
- **不装 App**：直接用手机浏览器打开电脑或服务器的地址，同样能看画布、答复审批，也能接收网页推送；手机宽度下页面自动换成适合手指的布局。

## 连接到你的电脑

先在电脑上打开「设置 → 远程访问」，打开「允许其他设备访问这台电脑」，点「连接手机」出二维码，详见[自托管部署与远程访问](/docs/server-and-devices/)。

1. 打开 App，首次进入是「连接到 Armadra」页。
2. 点「扫码」扫电脑上的二维码，或把「配对链接」粘进来再点「连接」。
3. 原生 App 会核对并记住这台电脑的证书指纹，之后只信任这一台，不需要手动装证书。手机浏览器则要按引导安装一次证书。
4. 配对成功后进入画布。

配对码一般两分钟过期，过期了在电脑上点「新配对码」。原生 App 在已经记住证书之后，还能用「输入配对码」，填电脑配对卡上显示的 8 位码。

如果提示二维码来自旧版或新版 Armadra，把电脑和 App 升级到同一个版本。连不上时，让手机和电脑在同一网络，或在电脑上打开「互联网访问」。

## 添加更多连接

一部手机可以记住多个连接，每个连接是一台电脑或服务器。在连接页点「添加连接」，有这几种方式：

- **扫码 / 配对链接 / 配对码**：局域网内连电脑，如上。
- **Armadra 云**：点「登录」，App 显示一个设备码并打开浏览器，在控制台核对设备码后点「授权」，回到 App 即可。登录用控制台支持的方式，见[团队与控制台](/docs/teams-and-console/)。之后可以选云上你有权访问的主机。
- **中转账号**：填中转的「地址」「账号」「口令」，自签的中转要核对「证书指纹」后点「信任并继续」，再在「选择主机」里勾选要连的在线主机。
- **分享链接 / 二维码**：别人分享给你的链接或二维码，扫一下直接加入。

连接列表里当前使用的标「当前」，团队的主机按团队分组；点某个连接切换，点「移除」忘掉它。

## 手机上能做什么

- **底部导航**：「画布」「文件」「Git」「设置」。一次只开一个面板，「画布」就是把它们都关掉。还没打开工作空间时，除「设置」外都灰着，因为手机要先在设置里配对。
- **单节点焦点页**：终端、编辑器与浏览器节点可以整屏打开（「全屏打开」），顶部有「返回画布」和「切换节点」。看到的是画布上的同一个节点，头部按钮、审批与状态都在。
- **终端按键条**：软键盘上方常驻 Esc、Tab、方向键与「粘贴」，点「Ctrl」展开 `^C`、`^D`、`^Z`、`^L`、`^R`、`^A`、`^E`、`^U`、`^K`，点一个发一个。系统键盘的按键不经过这条按键条。
- **Git**：分区列表、分区详情、单文件差异三级导航，每一级都有「返回」。
- **审批与回答**：Agent 等你答复时，节点头部或会话卡上有「允许」「拒绝」，和电脑上一样；要不要给你答复权限取决于你的角色，见[权限请求与审批](/docs/approvals/)。会话视图在手机上读起来更舒服，见[Agent 与 CLI](/docs/agents/)。
- **侧栏**：手机宽度下侧栏是一个抽屉，可以切项目、改名、搜索。
- 窗口方向：在设置里可选「界面方向」：跟随系统、竖屏或横屏。

输入的每个按键都带序号，断线重连后只重发还没确认的输入；超过十秒的不会自动重发，因为结果未知。

## 推送通知

登录后手机会问一次「接收审批与完成通知」，点「开启」。点通知直接打开对应节点。

- 在手机上可以分别打开或关闭这些类型：「等待审批」「等待回答」「Agent 停滞」「Agent 出错」「投递失败」「资源超过阈值」「评论里提到我」「有成果等你验收」「有事要你决定」。已登记的设备在电脑的「设置 → 通知」「推送设备」里。
- 手机浏览器使用网页推送，不需要任何第三方账号。
- 原生 App 的推送要由部署方提供推送凭据（或推送中继）。官方安装包目前没有配置推送中继，开启可能失败；Android 上装了 UnifiedPush 分发器时可以经它接收。拿不到推送时，仍可以打开 App 在侧栏「通知」里查看待处理的事。
- 推送内容是端到端加密的，不含终端原文与文件内容。

## 已知限制

手机不能在本机启动 Agent；一切执行都在连接的那台电脑或服务器上。
