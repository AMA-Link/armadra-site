这一篇用十分钟走完一次最小的协作：一个 Agent 实现，另一个审查。

## 1. 添加项目

打开 Armadra，在左侧栏的「项目」里点「添加项目」，选择一个代码目录。每个项目有自己的画布，Agent 默认在这个目录里启动。

## 2. 放两个 Agent 节点

在画布空白处右键（或点 Dock 上的 `+`），在「AI 助手」分组里选「新建 Claude Code」，再新建一个 Codex。没有安装的 CLI 会标为「未安装」。

每个节点都是一个真实终端，里面运行的就是 CLI 本身：登录状态、模型和权限沿用你平时的配置。节点头部会显示状态——运行中、需要你处理、已完成。

## 3. 连线

从一个节点的连线把手拖到另一个节点，就建立了一条连线。点连线可以设置关系：

- **对等**：双方都能按范围读取对方的上下文、给对方发消息；
- **主 → 从**：主节点可以向从节点派发任务，适合协调者与成员。

没有连线的节点彼此看不到。读取范围由连线决定，详见[连线与上下文](/docs/links-and-context/)。

## 4. 让它们协作

在 Claude Code 节点里正常提出任务，比如：

```text
给登录页加「记住我」，写测试。完成后把差异发给相连的 Codex 请它审查。
```

从画布启动的 Agent 会带上 Armadra 的画布技能，知道怎么查看相连节点、发消息、读收件箱。Codex 收到消息后读取差异并回复意见；你可以在两个终端里看到整个过程。

## 5. 处理权限请求

Agent 需要执行命令或写文件、而当前权限模式要求确认时，节点头部会出现权限请求。直接在头部回答即可，不用切到终端里找对话框。Armadra 不会替你回答权限提示。
