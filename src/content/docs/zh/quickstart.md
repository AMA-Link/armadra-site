这一篇用十分钟走完一次最小的协作：一个 AI 编程助手（Agent）负责实现，另一个负责审查。开始之前，请先[安装](/docs/install/)Armadra，并确认至少有两个 Agent CLI（例如 Claude Code 与 Codex）已经在本机装好并登录。

## 1. 添加项目

项目就是一个代码目录，Armadra 里称为工作空间。每个工作空间下可以有多张画布，Agent 默认在这个目录里启动。

1. 打开 Armadra，在左侧栏「这台电脑」分组的标题右边点「添加项目」（`+`）。
2. 在对话框里选一个来源：
   - **本地**：填目录路径；桌面版可以点「选择」用系统目录选择器；
   - **仓库**：从已连接的代码托管账号里搜索并选一个仓库；
   - **地址**：填仓库地址，选好父目录后「克隆」。
3. 添加后自动打开。桌面版也可以直接把文件夹拖到侧栏的项目区。

侧栏顶部的「新建画布」会在当前工作空间里再开一张画布；界面各区域的位置见[界面导览](/docs/interface-tour/)。

## 2. 放两个 Agent 节点

节点是画布上的一块内容，Agent 节点里运行的就是对应的 CLI。

1. 在画布空白处右键，或点底部 Dock 上的「新建」（`+`）。
2. 在「AI 助手」分组里选「新建 Claude Code」。
3. 再用同样的办法新建一个 Codex。没有安装的 CLI 会标为「未安装」。

登录状态、模型和权限沿用你平时的配置。节点头部的状态胶囊会显示它在做什么，例如「运行中」「等待审批」「等待回答」「已完成」。

## 3. 连线

连线决定谁能读到谁的内容。

1. 把鼠标移到一个节点边缘，拖动「连线」把手，落到另一个节点上。
2. 弹出「起个名字」对话框：给两端起短名字（小写字母、数字、`-` 或 `_`，最多 24 个字符），Agent 之间用 `@名字` 互相称呼。也可以点「跳过」，之后在节点菜单里补。
3. 同一个对话框里的「这条线的关系」有两个选项：
   - **共享上下文**（默认）：双方平级，可以互相读取、互发消息；
   - **派发**：一方向另一方派任务，适合协调者与成员。

没有连线的节点彼此看不到。关系之后可以改：右键点连线，选「设为共享上下文」「设为派发」或「反向派发」。详见[连线与上下文](/docs/links-and-context/)。

## 4. 让它们协作

在 Claude Code 节点里正常提出任务，比如：

```text
给登录页加「记住我」，写测试。完成后把差异发给相连的 Codex 请它审查。
```

从画布启动的 Agent 会带上 Armadra 的画布技能，知道怎么查看相连节点、发消息、读收件箱。Codex 收到消息后读取差异并回复意见；你可以在两个节点里看到整个过程。消息怎么传递见[消息与交接](/docs/messages-and-handoff/)。

## 5. 处理权限请求

Agent 需要执行命令或写文件、而当前权限模式要求确认时，请求会出现在节点头部，用「允许」「拒绝」或「回答」直接处理，不用在终端里找对话框。节点不在视野里时，侧栏顶部的「通知」（铃铛）会亮起一个点，点开能看到所有等待审批、等待回答、出错的节点，点一下跳过去。Armadra 不会替你回答权限提示，详见[权限与审批](/docs/approvals/)。
