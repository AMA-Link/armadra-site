画布是一张无限平面：节点承载 Agent 与资料，连线表达上下文共享和协作关系，分组帮助你组织不同任务，白板和评论让你在上面直接标注。这一页讲清楚画布上有什么、怎么摆放与整理。

一个工作空间（项目目录）下可以有多张画布，在侧栏里切换，每张画布各自保存。

## 节点种类

节点是画布上的一块独立内容。

| 节点 | 用途 | 怎么新建 |
| --- | --- | --- |
| 终端 | 普通 shell；运行 Claude Code、Codex 等 CLI 时就是 Agent 节点 | 「新建终端」「新建 <Agent 名>」；配置过 SSH 主机时，「远程终端」分组里每台主机一项 |
| 便签 | 任务说明、决定、待办；相连的 Agent 可以读取 | 「新建便签」 |
| 文件 | 浏览目录与文件，点文件在旁边打开编辑器 | 「新建文件管理器」 |
| 编辑器 | 编辑一个文件，带语言服务提示、Git 行标记，外部修改时提示合并 | 「打开文件…」（资源管理器里点文件）、「导入文件…」或拖入文件 |
| 变更 | 查看工作区或提交的 Git 变更 | 在 Agent 的会话视图里把改动卡片「落为变更节点」 |
| 浏览器 | 你和 Agent 共用的同一个网页会话 | 「新建浏览器」；只在桌面版或带浏览器的服务器上提供 |
| 分组 | 把一组节点框在一起 | 「新建画框」，或选中节点后右键「分组」 |

各节点的详细用法：Agent 见 [Agent](/docs/agents/)，编辑器、文件与浏览器见[编辑器与浏览器](/docs/editor-and-browser/)，变更见 [Git 与 GitHub](/docs/git-and-github/)。

## 新建与删除节点

- 在画布空白处右键，或点 Dock 上的「新建」（`+`），菜单分「终端」「AI 助手」「远程终端」「内容」「画布操作」几组，选一项新建。右键时节点以鼠标位置为中心，Dock 里则放在当前视野中央。
- 快捷键：`⌘T` 新建终端，`⇧⌘C` 新建 Agent。
- 新建的节点压在别的节点上时，会自动让开一小段，并且在你停在很小的缩放时自动调整视野，保证看得清。
- 选中节点按 `Delete` 或右键「删除」；节点里还有会话在运行时会先问「结束会话并删除？」。`⌘Z` 可以撤销。

## 摆放与整理

- **拖动与缩放**：拖节点标题移动，拖边角改变大小。右键节点可以「折叠」（只剩标题行）或「最大化」（占满画布，再选「还原」回到原样）。
- **多选**：框选，或按住 `Shift` 逐个加选；`⌘A` 全选。右键节点可以对选中的所有节点一起「复制」「折叠」「删除」。
- **一键整理**：Dock 上的「一键整理」按布局方向把节点排整齐；选中了节点就只整理选中的（「整理选中」）。右键它可以一次性选「纵向整理」或「横向整理」，默认方向在设置里。
- **适应视图**：Dock 右端的「适应」让所有内容入镜，右键选缩放档位。右下角的缩略图用来在大画布上定位。
- **锁定视图**：Dock 最左的锁防止不小心拖动相机；锁定时除「选择」外的白板工具不可用。
- **聚焦**：选中节点后 `⇧⌘F` 进入焦点模式，`⇧⌘⏎` 最大化。

## 分组

分组（也叫画框）把相关节点框在一起，方便按任务整理。

1. 选中几个节点，右键「分组」；或在空白处右键「新建画框」得到一个空框，再对节点右键「加入组」放进去。
2. 右键节点的「加入组」选择一个已有的组，「移出组」把它拿出来。
3. 右键组的「解组」拆开，里面的节点保留。
4. 一次导入多个文件时，它们会自动放进一个叫「导入」的组。

分组还可以绑定到 Git worktree，让一个 worktree 对应一个画框，见 [Git 与 GitHub](/docs/git-and-github/)。

## 白板

白板层与节点共用同一个视野与撤销栈：直接在画布上画图、写字，不需要新开节点。工具在 Dock 里，鼠标悬停看名称，按键切换：

| 工具 | 按键 | 说明 |
| --- | --- | --- |
| 选择 | `V` | 默认工具 |
| 手形 | `H` | 拖动平移 |
| 画笔 / 高亮 | `D` / `⇧D` | 手绘与荧光标记 |
| 形状 | `R` | 矩形、椭圆、菱形、三角形、六边形、星形 |
| 直线 / 箭头 | `L` / `A` | 画线与带箭头的线 |
| 文字 | `T` | 点一下放一段文字 |
| 引入… |  | 选图片或文件放到画布上 |

选中白板对象后会出现「样式」面板：颜色、粗细、线型（实线、虚线、点线）、填充（无填充、半透明、实心）、对齐与箭头。右键白板对象可以「置顶」「置底」「复制」「转成便签」「引用到 Agent」「删除」。`Esc` 回到选择工具。

**导入图表与外部内容**

- **Mermaid**：新建菜单的「导入 Mermaid…」（`⇧⌘M`）打开对话框，粘贴源码即可预览并导入。流程图会变成可编辑的白板图形，其他图种以图片导入。拖入 `.mmd` 或 `.mermaid` 文件、粘贴 Mermaid 源码，也会打开这个对话框。
- **图片**：拖入或粘贴图片，成为白板图片；SVG 会先转成位图。
- **文字与链接**：粘贴文本或网址，成为白板文字。
- **文件与目录**：拖入其他文件会复制到工作空间并打开编辑器，拖入目录得到文件节点。一次最多 256 个文件，单个不超过 16 MB，总计不超过 64 MB。

**把白板内容交给 Agent**

右键白板对象或分组（画框），选「引用到 Agent」，再选一个 Agent 节点；也可以从节点的连线把手拖一条线落到白板对象上。引用以灰色虚线表示，Agent 因此能读到这个对象：文字对象给正文，带文字的图形给文字和图片，手绘、直线与图片给图片。已经引用过会提示并选中那一条；每个 Agent 最多引用 64 个对象，超过会拦下并提示。右键引用线可以「重新同步引用」或「移除引用」，白板对象本身不受影响。

## 评论

评论用来在画布上留言、讨论和提到人。

1. 点 Dock 上的「评论」进入评论模式，右侧打开「评论」抽屉。
2. 在画布空白处或某个节点上点一下，写下评论；输入 `@` 可以提到成员，`⌘Enter` 发送。
3. 评论钉停在画布上，点开是线程，可以回复；每条评论可以编辑、删除，线程可以「解决」，之后还能「重新打开」。
4. 抽屉里的「只看未解决」过滤掉已解决的线程。

Agent 经连线读取一个节点时，会一并看到其上未解决的评论。再按一次「评论」或 `Esc` 退出评论模式。

## 保存与多人编辑

画布自动保存，Dock 右端的小圆点显示「已保存」「未保存」「保存中」或「保存失败」；保存失败时窗口顶部会出现带「重试」的提示。

自托管的服务器上，多人可以实时编辑同一张画布：能看到彼此的光标与选区，离线时的修改在重连后补齐；右上角的在线设备条显示谁在线。分享与权限见[服务器与设备](/docs/server-and-devices/)与[团队与控制台](/docs/teams-and-console/)。

## 状态

Agent 节点头部的状态胶囊在所有地方用同一套说法：运行中、空闲、等待审批、等待回答、已完成、已失败等。拿不到的数据显示为「状态未知」，而不是 0 或成功。
