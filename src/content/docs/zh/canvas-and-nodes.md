画布是一张无限平面：节点承载 Agent 与资料，连线表达上下文共享和协作关系，分组帮助你组织不同任务。

## 节点种类

| 节点 | 用途 |
| --- | --- |
| 终端（含 Agent） | 普通 shell，或运行 Claude Code、Codex 等 CLI 的 Agent 节点 |
| 便签 | 任务说明、决定、待办；Agent 可以经连线读取 |
| 分组 / Frame | 把一组节点框在一起，可绑定 worktree |
| 编辑器 | CodeMirror 6 编辑器，带语言服务与 Git 行边标记 |
| 差异 | 查看工作区或提交之间的 Git 差异 |
| 文件树 | 浏览项目文件 |
| 浏览器 | 人与 Agent 共用同一个浏览器会话 |
| 自动化 | Cron、间隔或一次性的定时计划 |
| Agent 活动 | 汇总 Agent 的子任务与进度 |

## 白板

白板层与节点共用相机和撤销栈：手绘、矩形与椭圆等形状、直线与箭头、文字、图片。Mermaid 流程图可以导入为可编辑的白板对象，其他图种以图片导入。白板对象与 Frame 可以「引用到 Agent」，以图片或文字成为 Agent 的资料。

## 评论

在画布上钉评论、回复成线程、`@` 提及。Agent 经连线读取一个节点时，会一并看到其上未解决的评论。

## 保存与多人编辑

画布自动保存。自托管部署（服务器壳）上多人可以实时编辑同一张画布：能看到彼此的光标与选区，离线时的修改在重连后补齐。

## 状态

Agent 节点的状态统一为四种：working（运行中）、waiting（等待中）、blocked（需要你处理）、done（已完成）。拿不到的数据显示为未知，而不是 0 或成功。
