# armadra-site

[Armadra](https://github.com/Owlbay/Armadra) 的官网：产品介绍、在线演示与文档。正式地址 <https://armadra.com>。

The official website of [Armadra](https://github.com/Owlbay/Armadra): product overview, live demo and documentation.

## 开发 / Development

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm check    # 类型与设计约束
pnpm build    # 输出 dist/
```

详见 [开发指南](docs/guides/development.md) 与 [部署指南](docs/guides/deployment.md)。贡献流程见 [CONTRIBUTING](.github/CONTRIBUTING.md)。
